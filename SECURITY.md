# Security policy

## Supported versions

Security fixes go into the latest release.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through GitHub:
<https://github.com/AliMilani/samovar-lite/security/advisories/new>

Include what you did, what happened, and a file or steps that reproduce it if you can. You should get
a first answer within a week. Once a fix is released, the advisory is published and you are credited
unless you prefer otherwise.

Samovar Lite passes media files and URLs to libmpv and FFmpeg. Problems in decoding itself are best
reported to those projects; problems in how Samovar Lite handles file names, playlists, drops, its settings
file or its single-instance socket belong here.
